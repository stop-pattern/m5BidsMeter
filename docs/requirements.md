# 製品要件メモ

この文書は現在有効な製品仕様を示します。新しい決定を反映するときは、該当箇所と文書全体を見直し、古い記述との矛盾を解消します。決定に至る作業経過は [作業ログ](work-log.md) に記録します。

## 確定していること

- このリポジトリは M5Stack Core2 向けのファームウェア開発に使う。
- `platformio.ini` の現行設定は PlatformIO の `m5stack-core2` 環境、`espressif32` プラットフォーム、Arduino フレームワークである。

## 未決定事項

以下は実装前に用途に応じて決める項目です。名前から仕様を補わないでください。

- メーターが表す値、単位、入力元
- 画面表示、操作方法、更新周期
- ネットワーク接続や認証が必要か
- データ欠損、通信失敗、再起動時の挙動
- 保存が必要な設定とその変更方法
- 実機で確認すべき完了条件
