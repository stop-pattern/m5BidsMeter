# 製品仕様

## 目的と入力

M5Stack Core2 に E233 系 TIMS を模した 320×240 画面を表示する。PC 側ゲームの BIDS v100/v202 ASCII 通信を USB シリアル 115200 bps、8N1、改行終端で取得する。[v202 コマンド仕様](https://gist.github.com/TetsuOtter/76b974d462276c9c993ddeb0b6a90cb0)、[v100 実装](https://github.com/Tralsys/BIDSid_SerCon)。`TRV202` で版を照会し、`TRIE1`（速度）、`TRIE3`（BC）、`TRIE4`（MR）、`TRIH0`（制動）、`TRIH1`（力行）を約 10 Hz で照会する。応答は `要求X値`。操作コマンドは送らない。選択中の保安装置に必要な `TRIPn` は保安装置画面で、CS-ATC の現示用 `TRIPn` は速度画面で約 5 Hz で照会する。

初期値は 0 とし、5 秒間有効応答がなければ最後の値を保持して「通信断」を表示する。警告はヘッダー右側に保安装置の赤点灯と同じ淡い赤の面・暗い文字で描き、読みやすい 16 px のゴシック体を使う。通信が正常な間は表示ごと消す。数値表示は四捨五入した整数。版番号は画面に出さない。

## 画面と操作

ホーム、速度計、圧力計、ブレーキ段数、保安装置、保安装置選択の 6 画面。起動時はホーム、ATS-P/Sn、輝度 100%、操作音量 50%。ホームには速度計、圧力計、ブレーキ段数、保安装置の 4 ボタンを上から縦一列に並べる。90 度回転して撮影された `img/top.jpg` と `img/menu1.jpg`、`img/menu2.png` を配置と色の参考にし、画面・ライトのボタンと同じ青灰色の立体的な角丸枠で描く。保安装置選択の 3 ボタンも同じ枠を使う。ホームの行は行先と表示名の一覧から生成し、今後 5 項目以上になった場合は 4 項目ずつページ送りできるようにする。表示画面から戻ったときはホームのページを維持する。

ホーム以外の左上に画面アイコンのボタンを置き、本体中央ボタン短押しと同様にホームへ戻る。中央を 0.8 秒長押しするとどの画面からも保安装置選択へ移り、選択後はホームへ戻る。左右の本体ボタンは未割当。全画面右下にライトのアイコンのボタンを置き、輝度を 25→50→75→100% と循環する。計器画面に保安装置の灯群は重ねない。

ホームではライトの左に同じ高さのスピーカーボタンを置き、操作音量を 50→0→100→50% と循環する。100% は設定した最大音量、50% はその半分、0% は消音とし、設定は保存しない。画面上の有効なボタン操作と本体中央ボタンの短押し・長押しで、音量が 0% 以外なら短い操作音を鳴らす。音は 2900 Hz と 5800 Hz の正弦波を同じ振幅で合成した 55 ms の PCM 波形とし、開始と終了を約 3 ms で減衰させる。50→0% の操作から音は止まり、0→100% の操作では鳴る。

画面・ライト・スピーカーのボタンは `img/display.png`、`img/bright.png`、`img/speaker.png` を基に青灰色の立体的な角丸ボタンと白い記号をコードで描く。画面記号は重なった 2 枚の四角、ライト記号は中心の丸と 8 本の光線とする。スピーカーは 0% で白枠のみ、50% で一部を白く塗り、100% では記号の内側をすべて白く塗る。

画面の更新時に全画面の消去過程を見せず、前回表示との差がある領域だけを書き換える。値、画面、通信状態、点滅位相が変わらないときは液晶に再送しない。転動防止警告の 0.5 秒間隔は保ち、画面全体のちらつきを起こさない。日本語表示は文字がつぶれないゴシック系フォントを用い、縦書きの長音記号「ー」は縦線として描く。長い灯名は枠内で複数列に組み、文字を切らずに表示する。

## 計器

- 速度計は 0～160 km/h。数値は実値を整数表示し、範囲外の針だけ端に収める。
- BC は 0～800 kPa、MR は 700～1000 kPa の縦目盛り。範囲外ではバーと指針だけ端に収める。
- 速度がちょうど 0 km/h、BC が 200 kPa 未満なら、BC の「200」と目盛りを赤 0.5 秒、通常 0.5 秒で点滅させる。初期値 0 にも適用し、実測 BC は表示し続ける。
- 制動 `H0=0` は緩解、1～8 は B1～B8、9 は非常。常用段は下から段数分のバーを点灯する。非常時はバーを消して「非常」を赤点灯する。力行 `H1<0` は段数と独立に「抑速」を緑点灯する。ブレーキ 1 段目が抑速かどうかは未確定。

### Panel インデックスの適用範囲

BVE の `Panel[n]` / `atsn` は路線ごとの共通番号ではなく、車両に組み込んだプラグインが出力する端子である。保安装置の選択名だけから任意の車両アドオンの番号を推定しない。本機の対応表は次の車両プラグイン構成を基準にする。別構成を使うときはその車両の `Vehicle`、ATS 構成とパネル定義を照合してから、対応表を選ぶ。

| 本機の選択 | 番号の基準 | 適用上の注意 |
| --- | --- | --- |
| ATS-P/Sn | [GeneralAtsPlugin の公開 Panel 端子表](https://docs.google.com/spreadsheets/d/1CSdf6mNsODLa-NJXdKwFiJQOXRoZTvDgMCOhIjAn7U4/edit#gid=211786497)の `ATS_East\snp.dll` / `snpST.dll` 系 | [東海道・宇都宮・高崎線向け E233-3000 車両データ](https://github.com/E233-3639/BVE_E233-3000_Data)は GeneralAtsPlugin を参照する実例。車両側の組合せ確認はなお必要。 |
| D-ATC | 山手線 E231-500 と京浜東北線 E233-1000 の候補として Mi5000 式を調査対象とする。[作者公開の v1.7 配布フォルダ](https://drive.google.com/drive/folders/1_M8hrlmvuOzbNPRt2Gfgvowa6-CHYpf9) | [山手線 E231-500 車両説明](https://sen719h33st.com/2022/06/e231-500/)には再編成式と Mi5000 式の両方が記載されるため、車両ごとに識別する。Mi5000 式の Panel 番号は説明書本文をまだ検証できておらず、番号を確定しない。 |
| CS-ATC / ATC-10 | [高橋うさお氏のメトロ総合プラグイン「車両作者向け指南」](http://www.nozomi.vc/71_ats/metro/train.htm)の 2017-09-19 版 | ATC-10 を含む車両でも別プラグインや変換プラグインなら番号が変わり得る。 |

ATS-P/Sn 基準の確定割当は P電源=2、パターン接近=3、ブレーキ開放=4、ATS-P=6、故障=7 とする。Panel 5 は「ブレーキ動作」一信号なので、常用・非常の二灯へ分配しない。ATS-Sn の白色灯=0、警報灯=1 は公開端子表にあるが、現画面の「ATS電源」「ATS動作」と同義かは車両パネル側で未確認のため未割当とする。同じ ATS-P でもメトロ総合プラグインは 2=P電源、3=パターン接近、4=ブレーキ動作、5=ATS-P、6=故障であり、4～6 をこの基準へ流用しない。[OpenBVE 標準プラグイン](https://openbve-project.net/documentation/HTML/train_panel2_cfg.html)の 256 以上の端子も別体系で、本機の BIDS Panel 0～255 へ流用しない。

Mi5000 式 D-ATC は公開配布物と採用車両を確認できたが、制限速度、中央下「×」・入換・パターン接近および保安装置灯の端子番号と値は未確定である。ATC-6 の Panel 定義を D-ATC に転用しない。番号と値を確認できるまでは現状の表示形状だけを使い、D-ATC 灯は消灯枠にする。

メトロ総合プラグイン基準の CS-ATC 灯は、ATC=19、ATC非常=22、ATC常用=23、非設=29、構内=31、過電流=96、対雪ブレーキ=175、ATS動作=1 を候補とする。Panel 96 は OLR 動作（0=通常、1=動作）であり、端子表の表示名は「過電流」である。Panel 92 はマスコンキーの状態値で、1=営団、6=国鉄・伊豆急として地下鉄/JR の表示へ使う。Panel 155「ホームドア連動」は 0=滅灯、1=連動、2=非連動であり、画面の「ホームドア」一般灯への直接割当はしない。Panel 73 は TASC 切換スイッチ（0=手動、1=TASC、作者資料では調整中）なので、TASC 灯へ割り当てない。資料の `ATC電源`、`TASC制御` などと画面表示の同義性が未確認の灯は消灯枠とする。灯の点灯条件は番号ごとの値定義を優先し、単純な非ゼロ判定は二値灯に限る。

速度計の針と数値、0～160 km/h の基本目盛りは ATS-P/Sn の現行表示を全方式の基礎とする。D-ATC は `img/d-atc_spd1.jpg` と `img/d-atc_spd2.jpg` に合わせ、0～120 km/h の同じ濃色の帯、針の回転中心を向く三角矢印、中央下の「×」、入換、パターン接近の表示灯を加える。矢印は 1 km/h 刻みで動ける構造とし、0 km/h は赤、それ以外は緑にする。D-ATC の制限速度と 3 灯の Panel 対応は未検証のため、実機では矢印を 0 km/h の赤い仮表示、3 灯を消灯枠とし、架空の現示・点灯は作らない。PC プレビューだけに 91 km/h の例を与えて矢印の形と刻みを確認する。

CS-ATC は `img/cs-atc_spd.png` の赤丸・緑丸と、回転中心を向く三角矢印を加える。メトロ総合プラグインの Panel 101 は中央下の赤い「×」、102 は 0 km/h、103 は廃止済み、104～124 は 10～110 km/h（5 km/h 刻み）、125 は 120 km/h の表示端子である。131 は停止の赤丸、132 は進行の緑丸の表示端子である。これらは車両パネル向け出力であり、ATC の生の信号コードではない。停止現示を優先し、複数の速度端子が同時に有効なら最も低い速度を選び、三角矢印は常に 1 つだけ表示する。0 km/h の三角は赤、それ以外は橙。131/132 が有効ならその丸灯を優先して表示し、両方が有効な異常時は停止の赤を優先する。どちらの丸灯も取得できない間は速度端子から停止・進行を暫定推定し、現示自体も不明なら赤丸とする。三角と丸は同時に表示する。参照画像にある 15・60・ATS動作の灯は速度計へ追加しない。
