# 製品要件メモ

## 確定していること

- このリポジトリは M5Stack Core2 向けのファームウェア開発に使う。
- `platformio.ini` の現行設定は PlatformIO の `m5stack-core2` 環境、`espressif32` プラットフォーム、Arduino フレームワークである。
- Codex が継続的に開発できるよう、決定済み要件と検証結果をリポジトリに残す。

## 未決定事項

以下は実装前に用途に応じて決める項目です。名前から仕様を補わないでください。

- メーターが表す値、単位、入力元
- 画面表示、操作方法、更新周期
- ネットワーク接続や認証が必要か
- データ欠損、通信失敗、再起動時の挙動
- 保存が必要な設定とその変更方法
- 実機で確認すべき完了条件

## 決定の記録方法

機能の依頼ごとに、決定した振る舞いと確認方法をこの文書に追記します。決定日や根拠となる依頼を必要に応じて添え、実装と食い違ったら同じ変更で更新します。
