# 製品仕様

## 目的と入力

M5Stack Core2 に E233 系 TIMS を模した 320×240 画面を表示する。PC 側ゲームの BIDS v100/v202 ASCII 通信を USB シリアル 115200 bps、8N1、改行終端で取得する。[v202 コマンド仕様](https://gist.github.com/TetsuOtter/76b974d462276c9c993ddeb0b6a90cb0)、[v100 実装](https://github.com/Tralsys/BIDSid_SerCon)。`TRV202` で版を照会し、`TRIE1`（速度）、`TRIE3`（BC）、`TRIE4`（MR）、`TRIH0`（制動）、`TRIH1`（力行）を約 10 Hz で照会する。応答は `要求X値`。操作コマンドは送らない。選択中の保安装置に必要な `TRIPn` は保安装置画面で、CS-ATC の現示用 `TRIPn` は速度画面で約 5 Hz で照会する。

初期値は 0 とし、5 秒間有効応答がなければ最後の値を保持して「通信断」を表示する。復帰時は通常表示に戻す。数値表示は四捨五入した整数。版番号は画面に出さない。

## 画面と操作

ホーム、速度計、圧力計、ブレーキ段数、保安装置、保安装置選択の 6 画面。起動時はホーム、ATS-P/Sn、輝度 100%。ホームで 4 表示画面を選ぶ。ホーム以外の左上に画面アイコンのボタンを置き、本体中央ボタン短押しと同様にホームへ戻る。中央を 0.8 秒長押しするとどの画面からも保安装置選択へ移り、選択後はホームへ戻る。左右の本体ボタンは未割当。全画面右下にライトのアイコンのボタンを置き、輝度を 25→50→75→100% と循環する。設定は保存しない。計器画面に保安装置の灯群は重ねない。

画面の更新時に全画面の消去過程を見せず、前回表示との差がある領域だけを書き換える。値、画面、通信状態、点滅位相が変わらないときは液晶に再送しない。転動防止警告の 0.5 秒間隔は保ち、画面全体のちらつきを起こさない。日本語表示は文字がつぶれないゴシック系フォントを用い、縦書きの長音記号「ー」は縦線として描く。長い灯名は枠内で複数列に組み、文字を切らずに表示する。

## 計器

- 速度計は 0～160 km/h。数値は実値を整数表示し、範囲外の針だけ端に収める。
- BC は 0～800 kPa、MR は 700～1000 kPa の縦目盛り。範囲外ではバーと指針だけ端に収める。
- 速度がちょうど 0 km/h、BC が 200 kPa 未満なら、BC の「200」と目盛りを赤 0.5 秒、通常 0.5 秒で点滅させる。初期値 0 にも適用し、実測 BC は表示し続ける。
- 制動 `H0=0` は緩解、1～8 は B1～B8、9 は非常。常用段は下から段数分のバーを点灯する。非常時はバーを消して「非常」を赤点灯する。力行 `H1<0` は段数と独立に「抑速」を緑点灯する。ブレーキ 1 段目が抑速かどうかは未確定。

## 保安装置

選択肢は ATS-P/Sn（E233-0/3000）、D-ATC（E233-1000）、CS-ATC/ATC-10（E233-2000）。灯の外観と並びはユーザー提供の `img/0.jpeg`、`img/1000.jpg`、`img/2000.jpg` を優先し、写真で判読できない項目は `memo/表示内容.md` を参照する。この 2 ディレクトリは手元の参照資料として保持し、コミットしない。Panel 対応が未確定の灯は消灯枠にする。個別指定のない灯は Panel 値が 0 以外なら点灯する。灯の点灯色は赤・橙・緑・白の 4 色を使い、消灯時は暗い枠と読める灰色の文字にする。

| 方式・領域 | 左からの表示灯 |
| --- | --- |
| ATS-P/Sn 上段 | P電源、パターン接近、常用ブレーキ、非常ブレーキ、ブレーキ開放、ATS-P、故障、ATS電源、ATS動作 |
| ATS-P/Sn 中段 | TASC電源、TASCパターン、TASCブレーキ、TASC切、TASC故障 |
| ATS-P/Sn 下段 | 転動防止ブレーキ、定位置、車両ドア全閉、ホームドア全閉、ホームドア連携、ホームドア分離、ホームドア開放 |
| D-ATC 左上 | 無表示、三相、非常短絡、耐雪ブレーキ、直通予備、定速、駐車ブレーキ |
| D-ATC 右上 | デジタルATC、ATC、切、ATS電源、パターン低減、非常運転 |
| D-ATC 右下 | ATC常用、ATC非常、停通防止動作、ATS動作、ATC電源、ATC開放 |
| CS-ATC 左上 | 過電流、三相、非常短絡、対雪ブレーキ、直通予備、非常運転、ATC開放、定速、駐車ブレーキ |
| CS-ATC 左下上段 | TASC、TASC制御、TASCブレーキ、ATO |
| CS-ATC 左下下段 | ホームドア、無文字枠、無文字枠（4 番目は枠なし） |
| CS-ATC 右上 | 地下鉄、JR、ATC常用、ATC非常、ATC電源 |
| CS-ATC 右下 | 構内、非設、ATC、ATS動作、ATS電源 |

`img/0.jpeg` で点灯状態を確認できる ATS-P/Sn の P電源は緑、ATS電源は白、TASC電源は緑、TASC切は橙とする。消灯中の灯の点灯色は写真だけでは確定できないため、赤・橙・緑・白のうち灯の意味から暫定色を選ぶ。対応する点灯写真または色の一覧を受けたら全方式の色表を確定する。異なる方式の灯群は画像の左・右および上下のまとまりを保ち、単純な全幅の等間隔行へ混ぜない。

[公開端子表](https://docs.google.com/spreadsheets/d/1CSdf6mNsODLa-NJXdKwFiJQOXRoZTvDgMCOhIjAn7U4/edit#gid=211786497)により ATS-P/Sn の P電源=Panel 2、パターン接近=3、ブレーキ開放=4、ATS-P=6、故障=7 とする。同表の Panel 5「ブレーキ動作」は常用・非常を区別しないため割り当てない。ATC-6 の定義は D-ATC に転用しない。

CS-ATC は[メトロ総合プラグインの Panel 表](http://www.nozomi.vc/71_ats/metro/train.htm)を入力に使う。ATC=19、ATC非常=22、ATC常用=23、非設=29、構内=31、過電流=96、対雪ブレーキ=175、ATS動作=1 は 0 以外で点灯。地下鉄/JR は Panel 92 の値 1/6、TASC は 73=1、ホームドアは 155=1 で点灯する。他の灯は対応資料ができるまで消灯する。

D-ATC と CS-ATC の速度計には制限速度の三角形を描く。CS-ATC は Panel 101 を赤い「×」、102 を 0 km/h、104～124 を 10～110 km/h（5 km/h 刻み）、125 を 120 km/h の現示として扱う。停止現示を優先し、複数の速度現示があれば最も低い速度を採用する。有効な速度現示は緑の三角形で示す。現示がない場合、および対応表のない D-ATC は 0 km/h に赤い三角形と「×」を表示する。
