# 製品仕様

## 目的と構成

PC の鉄道運転ゲームから BIDS v202 形式の情報を USB シリアル通信で受信し、M5Stack Core2 のディスプレイにグラフィカルに表示する。ファームウェアは `platformio.ini` の `m5stack-core2` 環境（`espressif32`、Arduino）で開発する。現在の `src/main.cpp` は生成時サンプルであり、以下の機能はまだ実装されていない。

## 画面と操作

画面は E233 系の TIMS 表示を模倣したデザインとする。ディスプレイ左上に表示内容切替スイッチを置き、速度計、圧力計、ブレーキ段数表示、保安装置表示の4画面から表示する画面を選べるようにする。切替方法の細部と、TIMS のどの画面・意匠を再現するかは未決定である。

| 画面 | 表示する情報 | 決定済みの条件 |
| --- | --- | --- |
| 速度計 | 列車速度（km/h） | 目盛りの最大値は 160 km/h |
| 圧力計 | BC 圧と MR 圧（kPa） | 下記の転動防止表示を含む |
| ブレーキ段数表示 | 制動ハンドルの段数 | 段数の表示形式は未決定 |
| 保安装置表示 | ゲームから取得した保安装置の状態 | 対象となる状態と表示方法は未決定 |

### BC/MR 画面の転動防止表示

列車速度が **0 km/h** で、かつ BC 圧が **200 kPa 未満** のとき、転動防止表示として **「200 kPa」を赤く点滅**させる。BC 圧がちょうど 200 kPa の場合は「未満」に該当しない。走行中は、BC 圧が 200 kPa 未満でもこの条件には該当しない。点滅周期、および警告中に実測 BC 圧をどう併記するかは未決定である。

## BIDS v202 の情報対応

BIDS v202 の公開 [ASCII コマンド資料](https://gist.github.com/TetsuOtter/76b974d462276c9c993ddeb0b6a90cb0) には、運転情報要求の項目として次が定義されている。下表は表示に必要な情報の候補を示すもので、通信方式の実装詳細を確定するものではない。

| 用途 | BIDS の項目 |
| --- | --- |
| 速度計と転動防止判定 | State Data `E1`：列車速度（km/h） |
| BC 圧 | State Data `E3`：BC 圧（kPa） |
| MR 圧 | State Data `E4`：MR 圧（kPa） |
| ブレーキ段数 | Handle Position `H0`：制動ハンドル位置。Spec Data `C0` は制動ノッチ段数 |
| 保安装置表示 | Panel `Pn`：n 番のパネル状態。必要な番号はゲーム・車両側の定義に依存する |

通信速度、受信データの形式、要求・応答の順序、更新周期、接続断やデータ欠損時の扱いは、接続する PC 側の BIDS 実装に合わせて決める。資料に項目があることだけを根拠に、値の送信方法やパネル番号を推測しない。
